# Scoring is deterministic

A Score is a pure function of the Couch arrangement, the Shelf, and Run state; no effect may introduce chance at scoring time. Randomness lives only in draws, Shop offers, and Disaster selection. This makes an exact pre-Play score preview possible and keeps the promise that Cats never undermine the player's arrangement. The genre precedent (Balatro's probabilistic jokers) makes this a non-obvious choice, so "25% chance to…" House Cats are ruled out by design, not by oversight.
