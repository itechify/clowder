# Scoring resolves in fixed phases, not Shelf order

A Play resolves in four fixed phases: (1) Gatherings and whole-Play effects add Mult, (2) each Cat's Scoring events and Repeats add Purr and any per-score Mult, (3) all × Mult effects apply, (4) Score = Purr × Mult. We rejected Balatro-style left-to-right House Cat resolution, where Shelf order changes the result, because the design goal is that a player can explain any absurd Score, and because the Couch should be the only spatial puzzle. Shelf order matters only for effects that explicitly reference position (Copycat).
