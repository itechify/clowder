# Phaser renders the game; React only renders the shell

Clowder should feel like a game, not a card-shaped web UI, so every in-Run surface (living room, Couch, Hand, Shelf, Shop) is drawn in Phaser, with Cats picked up, seated, and scored as animated objects. React is limited to the shell around it: settings, PWA install and update prompts, and between-Run screens. We rejected a DOM/React-only build, which would be quicker for a prototype and better for accessibility, because it pulls the feel toward menus and panels. Scoring and all rules live in a pure TypeScript engine with no Phaser dependency, so the renderer stays swappable and the score preview and tests use the same code the game does. Toolchain mirrors the author's existing Phaser project (pnpm, Vite, TypeScript, Biome, Vitest, Playwright, Workbox PWA) for web and mobile.
